# 14.zettel-writer-connect 운영가이드

이 파일은 `14.zettel-writer-connect` 프로젝트의 운영가이드 SSOT 진입점이다. 운영 세부 전체는 바로 옆 상세 문서에 보존한다.

## 먼저 읽을 전역 지침

| 순서 | 파일 | 언제 읽는가 |
|---|---|---|
| 1 | `~/.claude/CLAUDE.md` | 모든 비단순 프로젝트 작업 시작 전 |
| 2 | `~/.claude/common_rules.md` | 보안, 권한, SSOT, 보고 형식 확인 |
| 3 | `~/.claude/common_rules.d/context-trigger-method.md` | 운영가이드·지침이 길거나 분리 기준을 판단할 때 |
| 4 | `~/.claude/common_rules.d/instruction-maintenance.md` | AGENTS.md, CLAUDE.md, 운영가이드, 스킬을 수정할 때 |
