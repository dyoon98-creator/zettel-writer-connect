# 확인 모드 — 위에 `concept_carried: true` 가 **있을 때만** 적용
작성자는 컨셉 마법사에서 이미 컨셉 단락을 썼다. 거기에 「누구에게 무엇을」이 대개 들어 있다. **백지에서 묻지 말고 읽어서 확인받는다.**

- `intro` — `concept_paragraph` 에서 읽어낸 독자(turn 0) 또는 핵심 메시지(turn 1)를 한 문장으로 되짚는다.
- `question` — "이 독자가 맞을까요?" / "이 메시지로 가도 될까요?" 형태의 **확인 질문**.
- `options` 5개 —
  1. **반드시 `맞습니다 — <이어받은 값 20자 내>` 로 시작한다.**
  2~4. `concept_paragraph` · `concept_memo_strong_sentences` 를 근거로 한 다른 후보 세 개.
  5. 항상 **"직접 입력"** — 「고치겠습니다」의 자리. 여기서 바로 고쳐 쓴다.
- `prior_interview.target_reader` / `prior_interview.core_message` 가 있으면 그 값을 1번 선택지의 근거로 우선한다.

`concept_carried` 가 **없으면** 이 절을 무시하고 아래대로 평소처럼 묻는다.

# 장르별 독자/메시지 옵션 가이드 (structured_handoff의 draft_genre 참조)

## investment-report / investment-strategy-memo / legal-accounting-review 장르
- 독자는 고객 중심 (투자 보고, 브리핑, 검토 수신자).
- turn 0 (독자) 옵션 예시: "기존 고객" / "잠재 고객" / "LP·수탁자" / "내부 의사결정자" / "직접 입력"
- turn 1 (메시지) 옵션: 거래 판단·위험 인식·행동 유도·신뢰 구축 관련 구체 한 줄. 감성 예시 금지.
- "글쓰기를 막 시작한 사람" 등 일반 글쓰기 독자 예시 금지.

## column-essay / long-form-manuscript 장르
- turn 0 (독자) 옵션 예시: "한 분야에서 갓 졸업한 사람" / "어느 한 직업의 동료" / "10년 후의 나" / "같은 고민을 가진 독자" / "직접 입력"
- turn 1 (메시지) 옵션: 작가가 독자에게 끌어들일 수 있는 구체 한 줄.

## lecture-presentation 장르
- turn 0 (독자) 옵션 예시: "현업 실무자" / "수강생·학생" / "비전공 의사결정자" / "내부 팀원" / "직접 입력"
