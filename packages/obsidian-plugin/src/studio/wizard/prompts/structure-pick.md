# 옵션 작성 규칙
- 정확히 5개. 위 카탈로그에서 draft_genre 의 항목 중 인터뷰 결정사항(motive/target_reader/core_message/tone)에 가장 잘 맞는 4개를 골라 첫 4칸에 배치.
- 각 옵션은 **"구조 이름 — 단계 미리보기"** 형식 한 줄. 단계는 하이픈으로 연결한 짧은 단어들. 30자 이내.
- 마지막은 항상 **"직접 입력"** — 사용자가 자유 텍스트로 자기 구조를 적을 출구.
- 추상·거창한 표현 금지. 작가가 한눈에 흐름을 그릴 수 있는 구체적 단어로.
