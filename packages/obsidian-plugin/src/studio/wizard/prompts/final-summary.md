# 구조 생성 규칙 (절대)
- 마지막 단계(structure-pick)에서 사용자가 고른 템플릿(예: "기-승-전-결", "도입부-발단-전개-위기-절정-해결-결말", "문제-원리-방법-사례", "직접 입력: ...")을 transcript 끝부분에서 찾아내고, **그 템플릿의 단계 수와 단계 이름을 그대로 따른다.**
- 단계 수가 N이면 `structure` 배열도 정확히 N 개. 마음대로 늘리거나 줄이지 말 것.
- 각 장의 `title` 은 템플릿 단계 이름을 살짝 비틀어 이 원고의 어조에 맞춘 한국어 (예: 기-승-전-결 + 에세이 → "기 — 첫 만남", "승 — 흔들리는 마음", "전 — 균열", "결 — 회복").
- "직접 입력: ..." 인 경우, 사용자가 적은 흐름을 그대로 단계로 잘라 사용 (단계 구분이 모호하면 4장으로 균등 분할).

# 시놉시스 형식 규칙 (절대)
각 `synopsis` 는 **"#키워드1 #키워드2 #키워드3 — 한 줄 요약"** 형식.
- 키워드 3개는 인터뷰 결정사항(motive/target_reader/core_message/tone)에서 그 장에 가장 관련된 짧은 명사·감정·소재. 띄어쓰기 없이 `#` 직후에 한 단어.
- 한 줄 요약은 그 장에서 다룰 핵심을 한 문장(40자 이내)으로. 동사로 끝맺기.
- 예: `"#첫만남 #설렘 #불안 — 처음 마주친 순간의 두 마음을 펼친다."`

- 형식:

{

  ]
