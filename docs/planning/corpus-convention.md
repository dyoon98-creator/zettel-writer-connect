# Voice Corpus Convention

> 참조 문서. 볼트 실제 파일은 대표님 승인 후 corpus-readme-template.md 기반으로 생성.

## 1. 권장 폴더

| 항목 | 값 |
|---|---|
| **권장 vault 경로** | `_voice-samples/` (vault root 기준) |
| **현재 플러그인 기본값** | `_attachments/voice/` (VoicePane 기본) |
| **적용 방법** | VoicePane → "폴더 선택…" (Obsidian 모드에서 picker 비작동 → 텍스트 경로 fallback 필요, B2.3 예정) |

`_voice-samples/` 를 권장하는 이유: `_attachments/voice/` 는 기존 파일 경로와 충돌 가능. `_voice-samples/` 는 명칭에서 용도가 명확하고 Obsidian 검색/그래프에서 분리 용이.

## 2. 파일 규칙

| 항목 | 규칙 |
|---|---|
| **형식** | `.md` 만 허용 |
| **네이밍** | `YYYY-MM-DD-<주제>.md` 권장 (예: `2026-05-01-투자위원회메모.md`) |
| **최소 샘플 수** | 5개 이상 권장 |
| **최소 파일 길이** | 파일당 500자 이상 권장 |
| **내용 종류** | 대표님이 직접 쓴 자연스러운 한국어 글. 이메일·메모·카카오톡·보고서 등 다양한 형식 권장 |

## 3. 포함/제외 원칙

- 포함 여부는 대표님이 결정. 법률 의견·펀드·회사 자료도 대표님이 승인하면 포함 가능.
- 대표님 승인 없는 자동 포함은 금지 (corpus-governance.md §2 참조).
- frontmatter `voice-exclude: true` 태그 → 향후 B3에서 필터 구현 예정. 현재는 폴더에서 물리적 제외.

## 4. 샘플 내용 다양성 권장

AI 문체 분석 정확도를 높이려면 아래 형식을 고루 포함:
- 이메일 (격식체)
- 카카오톡·텔레그램 (비격식/간결체)
- 보고서·메모 (사실 중심 서술체)
- 에세이·칼럼 (논리 전개 서술체)

## 5. 레지스터별 가이드 (미래 B3)

현재 StyleGuide는 전역 단일 가이드. 이메일/카카오/보고서별 delta 가이드는 B3에서 구현.
